# Number Range Summarizer

Produces a comma delimited list of numbers, grouping sequential numbers into ranges.

Example: `1,3,6,7,8,12,13,14,15,21,22,23,24,31` -> `1, 3, 6-8, 12-15, 21-24, 31`

## Requirements
- Java 8+
- Maven 3.6+

## Build and test
```
mvn clean test
```
